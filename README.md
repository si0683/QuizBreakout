# Quiz Breakout

Образовательная браузерная игра: арканоид с образовательным квизом. HTML, CSS и чистый JavaScript (Canvas), графика из эмодзи, без библиотек и сборки.
Сделана для уроков программирования по промту [edu_game](https://stassy-ni.github.io/edu_game.html), код подробно прокомментирован на русском.

**Играть:** https://si0683.github.io/QuizBreakout/

## Возможности

- Платформа с героем отбивает шар, шар разбивает кирпичи; кирпичи-враги прочные (число ударов на кирпиче).
- Разбил золотой кирпич ❓ — пауза и вопрос, верный ответ — выбор 1 из 3 бонусов (14 бонусов: мульти-шар, лазеры, огненный шар…).
- Каждый 3-й уровень — босс с полоской здоровья, который ходит и стреляет.
- Платформа управляется клавишами, мышью или пальцем, угол отскока зависит от места удара.
- 3 мира: Фэнтези, Космос, Эко-Панк; предметы: математика, русский, английский, история России; ответ кнопками или вводом.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Платформа | `←` `→`, `A` `D` или мышь | вести пальцем |
| Запуск шара | `Пробел` / `↑` | тап |
| Ответ / выбор | мышь или `1`–`4` | тап |
| Пауза | `Esc` / `P` | ⏸ |

## Файлы

```
index.html   — разметка: экраны (меню, сложность, вопрос, улучшения, настройки, пауза, конец игры) и HUD
style.css    — оформление: цвета, шрифты, кнопки, анимации
script.js    — логика: Лаборатория, вопросы, улучшения, игра, рисование, управление
sound/       — звуки: jump, coin, tick, start, crash
PROMPT.md    — промт для нейросети: подробное ТЗ + полные исходники + ссылки на звуки
PROMPT_QWEN.md — инструкция для урока: Qwen быстро берёт готовые файлы по ссылкам, и они вставляются в CodePen
AGENTS.md    — правила для ИИ-агентов (PROMPT.md обновляется вместе с игрой)
codepen/index.pen.html — готовый HTML для CodePen (создаётся автоматически)
tools/build.py — обновляет исходники в PROMPT.md и файл codepen/index.pen.html
```

После любого изменения кода:

```bash
python tools/build.py
```

## Лаборатория

В самом начале `script.js` — раздел **«0. Лаборатория игры 🧪»**: 10 настроек для экспериментов с детьми. По умолчанию игра обычная.

- `titleTop` — название в меню
- `heroEmoji` — свой герой на платформе
- `lives` — жизни
- `paddleWidth` — ширина платформы
- `ballSpeed` — скорость шара
- `quizBricks` — кирпичей с вопросом на уровне
- `brickRows` — рядов кирпичей
- `bossEvery` — босс каждые n уровней
- `startBalls` — шаров на старте
- `rainbowBall` — радужный шар

## Запуск на компьютере

Звуки загружаются через `fetch`, поэтому запустите простой сервер из папки игры:

```bash
python -m http.server 8000
```

После этого откройте http://localhost:8000.

## Публикация

- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main`, `/ (root)`. Игра будет на https://si0683.github.io/QuizBreakout/
- **CodePen:** в `index.pen.html` (окно HTML) — весь файл `codepen/index.pen.html`, в CSS — `style.css`, в JS — `script.js`. ⚠️ Не вставляйте `index.html` целиком: скрипт загрузится дважды. Звуки в CodePen берутся с GitHub Pages.

Для демонстрации на уроке используйте [`PROMPT_QWEN.md`](PROMPT_QWEN.md).
